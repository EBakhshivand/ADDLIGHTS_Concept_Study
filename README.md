# ADDLIGHTS_Concept_Study
This repository contains the FE input files used for the validation study of AM-LSF systems.

* For GW_AM-LSF system:
  * "GSL42015.inp" is the main input file and "GSL42015_imperfection.inp" is its corresponding imperfection file.

* For KW_AM-LSF system:
  * "KSW42033.inp" is the main input file and "KSW42033_imperfection.inp" is its corresponding imperfection file.
